## 📖 Overview

This repository showcases a complete Data Engineering pipeline built entirely within Microsoft Fabric. The main goal is to explore the Fabric ecosystem practically by developing a Customer 360 solution—taking it from the initial raw data ingestion all the way to dynamic business reporting. 

It highlights key phases like data loading, transformation, modeling, and visualization leveraging Fabric tools including Lakehouse, Spark Notebooks, Delta Tables, and Power BI.

## 🚀 Project Workflow

- Ingest raw Parquet files into the Fabric Lakehouse
- Cleanse and transform the data utilizing PySpark
- Save the refined data into Delta Tables
- Develop a unified Customer 360 data model
- Design an interactive Power BI report

## 🛠️ Tech Stack

- Microsoft Fabric
- Fabric Lakehouse
- PySpark
- Delta Lake
- Power BI
- Parquet

## 📂 Dataset

The analysis is built upon the following datasets:

- Customers
- Orders
- Payments
- Support Tickets
- Web Activities

## ✨ Features

- Extracting data directly from Parquet sources
- Data cleansing and preparation via PySpark
- Managing nulls and eliminating duplicate records
- Standardizing data types across tables
- Generating and managing Delta Tables
- Integrating a unified Customer 360 view
- Delivering dynamic visual insights via Power BI

## 📊 Dashboard Insights

The final report visualizes key metrics across:

- Customer Demographic Overview
- Sales and Order Tracking
- Payment and Revenue Summaries
- Support Ticket Monitoring
- User Web Behavior Analysis
